# Print material

Not part of the website. These live in the repo so they stay reproducible
and versioned with the brand they use — but note that GitHub Pages serves
the whole repo root, so both files are also reachable at
`alejandrobarberpro.com/print/…`. That is deliberate and useful: Alejandro
can open the PDF on his phone and send it to a print shop without anyone
having to find a file for him.

## `scan-to-book.pdf` / `.html`

A letter-size sign — crown, name, QR to the homepage, and "scan to book"
in the site's three languages. Print at **100% / Actual size**; "fit to
page" still scans (the QR is vector) but shifts the margins.

The HTML is the source, the PDF is the artefact. To regenerate after
editing the HTML:

```sh
python3 -m http.server 8096          # from the repo root
chrome --headless=new --no-pdf-header-footer \
  --print-to-pdf=print/scan-to-book.pdf \
  http://localhost:8096/print/scan-to-book.html
```

It must be served over HTTP, not opened as a `file://` path — the crown is
a CSS `mask` and the fonts are `woff2`, and both are blocked by the
file-protocol origin rules.

Verified on the committed PDF: one page, MediaBox 612x792pt (8.5x11in),
all four faces embedded and subsetted — Cormorant Garamond, Inter regular
and semibold, and Microsoft YaHei for the Chinese line.

## The QR itself

`assets/qr.svg` and `assets/qr.png`, generated by `scripts/make-qr.py`.
Both encode `https://alejandrobarberpro.com` at error-correction level Q.
The script decodes its own output and fails if it does not read back as
that URL, so a broken code cannot be committed silently.

Send the **SVG** to a printer — it is geometry, and rasterising it only
loses edge definition. The PNG is for places that will not take an SVG.
